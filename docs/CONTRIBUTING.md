# Guide de Contribution à CodeSync

Merci de votre intérêt pour CodeSync ! Nous apprécions les contributions de la communauté. Ce guide vous aidera à démarrer.

## Code de Conduite

Ce projet et tous ceux qui y participent sont régis par notre Code de Conduite. En participant, vous vous engagez à respecter ce code. 

## Comment Contribuer ?

### Rapporter un Bug

Si vous trouvez un bug, veuillez vous assurer qu'il n'a pas déjà été signalé en consultant les Issues du projet. Si ce n'est pas le cas, ouvrez une nouvelle issue en fournissant une description claire et concise du problème, les étapes pour le reproduire, et le comportement attendu.

### Suggérer une Amélioration

Si vous avez une idée pour améliorer l'application, nous serions ravis de l'entendre ! Ouvrez une issue en décrivant votre suggestion en détail. Expliquez pourquoi cette fonctionnalité serait utile et comment elle pourrait être implémentée.

### Votre Première Contribution

Prêt à contribuer au code ? Voici comment procéder :

1.  **Forkez le projet**.
2.  **Clonez votre fork** sur votre machine locale.
3.  **Créez une nouvelle branche** pour vos modifications (`git checkout -b feature/nom-de-votre-feature`).
4.  **Faites vos modifications** dans le code.
5.  **Commitez vos changements** avec un message clair et descriptif (`git commit -m "feat: Ajout de la fonctionnalité X"`).
6.  **Poussez vos changements** vers votre fork (`git push origin feature/nom-de-votre-feature`).
7.  **Ouvrez une Pull Request (PR)** vers la branche `main` du projet original.

Votre PR sera examinée par les mainteneurs du projet. Des modifications pourront vous être demandées avant qu'elle ne soit fusionnée.

Merci encore pour votre contribution !
