# CodeSync : Python & JS

Bienvenue sur CodeSync, une application web moderne et intuitive conçue pour les débutants souhaitant apprendre la programmation en Python et JavaScript de manière simultanée et comparative.

## ✨ Fonctionnalités

-   **Apprentissage Comparatif :** Chaque concept est expliqué côte à côte pour Python et JavaScript, vous aidant à comprendre les similitudes et les différences fondamentales entre les deux langages.
-   **Contenu Généré par IA :** Les leçons sont dynamiquement générées par l'API Gemini de Google, garantissant des explications claires, concises et à jour.
-   **Suivi de Progression :** Un système de progression visuel vous permet de suivre votre avancement à travers les chapitres et de savoir où vous vous êtes arrêté.
-   **Mode Clair & Sombre :** Personnalisez votre expérience d'apprentissage avec un thème clair ou sombre pour le confort de vos yeux.
-   **Responsive Design :** Apprenez n'importe où, sur n'importe quel appareil, que ce soit un ordinateur de bureau, une tablette ou un mobile.
-   **Idées de Projets :** À la fin du cours, découvrez une liste d'idées de projets innovants pour mettre en pratique vos nouvelles compétences.

## 🚀 Démarrage

L'application est conçue pour être utilisée directement dans le navigateur. Aucune installation n'est requise. Il vous suffit d'ouvrir le lien et de commencer votre parcours d'apprentissage.

## 🛠️ Structure du Projet

Le projet est construit avec une stack technologique moderne :

-   **Frontend :** React avec TypeScript
-   **Styling :** Tailwind CSS
-   **IA :** Google Gemini API

La structure des fichiers est organisée pour une maintenabilité et une lisibilité optimales, avec une séparation claire entre les composants, les services, les hooks et les constantes.
